# Plumber Diary

App Android per idraulici (e tecnici sul campo in generale) che traccia
automaticamente le posizioni durante la giornata, misura il tempo di
permanenza, propone un recap serale correggibile con associazione cliente,
supporta squadre multiutente e genera mandatini ore / rapportini in PDF.

- **`context.md`** — obiettivo, requisiti, analisi di mercato, decisioni
  architetturali (leggere prima di modificare qualunque cosa).
- **`manual.md`** — manuale funzionale/utente.
- **`changelog.md`** — cronologia delle versioni.
- **`CLAUDE.md`** — regole operative per chi (o cosa) sviluppa su questo repo.
- **`app/`** — scaffolding Android (Kotlin, Jetpack Compose) — vedi
  `app/README.md` per lo stato e i passaggi manuali richiesti.
- **`backend/`** — Vercel Functions + Firestore rules — vedi
  `backend/README.md`.
- Mockup interattivo delle schermate: link in `context.md`.
